# AVR Slots Game

Slots game made with usage of AVR microcontroller 
Used elements: 
- ATMega328PB
- 7 seg display
- keyboard 4x4
- diodes with resistors attached to them

Language- C

HOW IT WORKS?
- game logic is like in casino slots in real life (3 same numbers - you win the best price, 2- you win less, else you win nothing)
- implemented slots spinning
- you can switch between your account balance and slots screen
- you can change a size of bet
- when you win diodes start shining
